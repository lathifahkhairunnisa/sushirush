# eatstime — Sushi Rush 🍣

Game web bertema sushi berbahasa Indonesia dengan desain modern minimalis.

## Fitur
- Game Sushi Rush
- Sistem skor, kombo, level, dan timer
- Misi harian
- Koleksi sushi yang dapat ditemukan
- Rekor pribadi menggunakan localStorage
- Pause game
- Cara bermain
- Random sushi order
- Responsive & fluid
- Tidak membutuhkan backend
- Siap deploy ke GitHub Pages

## Struktur
- index.html
- style.css
- script.js

## Deploy ke GitHub Pages
1. Extract ZIP.
2. Upload semua file ke repository GitHub.
3. Masuk ke Settings > Pages.
4. Pilih Deploy from a branch.
5. Pilih branch main dan folder /(root).
6. Simpan, lalu tunggu link GitHub Pages aktif.
